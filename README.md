# Карточки

Mobile-first FR→RU vocabulary flashcards with assisted word entry (dictionary + Claude suggestions), screenshot import, automatic slang-level detection and auto-sorted themes. Deployed on Vercel.

- `prototype/Petit_Argot.html`: the original one-file prototype (v1)
- `mockups/`: UI/UX mockups for v2 (Design-canvas `.dc.html` artboards, 390×844) plus `SPEC.md`, the design spec
- `docs/plan.md`: the implementation plan; `docs/research.md`: the stack and prior-art research behind it

Status: Phase 0 (mockups v3, index-card style), awaiting review before building the app.
