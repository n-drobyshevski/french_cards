# «Карточки» — mockup spec v3 (shared by every designer agent)

Product: mobile-first PWA of vocabulary flashcards, French → Russian (it is NOT a "slang app" — slang is
just one dimension: every word gets a detected slang level). App name everywhere: **Карточки для Лизи** (renamed 2026-10-22; home-screen label stays «Карточки»)
(plain, no tagline about slang). Single user. UI copy is **Russian**; card words are **French**.

## v3 DIRECTION — read this first, it overrides any older habit
The user said the previous mockups looked "AI-styled". v3 must NOT look like a generic AI-generated app:
- Sparkle: only as the ink «spark» glyph (Icons `spark`, `spark-refresh`, `spark-plus`: thin 1.5px four-point stars, ink colour, never filled, coloured or animated) on buttons that call Claude — «Заполнить автоматически», «Определить уровень и часть речи», «Другой пример» ↻, «+ Ещё пример» / «Подобрать пример», «Разложить» / «Разложить по темам», «Дополнить карточки», «Расформировать», «Распознать заново» (option B of canvas «Пометка ИИ — варианты», chosen 2026-10-22). No other magic imagery. NO «ИИ» / «AI» labels in the UI, except the Settings section «ИИ» and its privacy line (changed 2026-10-22 at the user's request).
  Automatic features just work quietly and are described by what they do: «Варианты», «подобрано автоматически»,
  «догадка» (translation not visible on screenshot), «Разложить по темам».
- NO pastel pill soup, no tinted icon chips, no soft drop shadows, no big rounded "bubbly" cards, no gradient, no shimmer.
- Concept: **a paper index card / library card catalog**. Ink on paper, hairline rules, dictionary typography.
  Square-ish geometry (radius 4–8px), 1px rules, black primary buttons, ONE red ink accent used sparingly
  (the index-card red rule line, active states, counts that need attention).
- Metadata reads like a dictionary entry: part of speech and register as italic abbreviations
  (*n. f.*, *v. pron.*, *fam.*, *arg.*, *verl.*, *vulg.*), small caps / mono for counts and labels.

Every artboard is one file `project/<Name>.dc.html`, fixed root 390×844 (phone). Exact skeleton:

```html
  ... screen ...

}
</script>

```

Rules that bite:
- Keep `<script src="./support.js"></script>` EXACTLY. Close every non-void element, quote every attribute. `&` in URLs inside attributes → `&amp;`.
- Styling: inline `style="…"` on elements for everything design-specific (the editor edits these). `<helmet><style>` ONLY for `body{margin:0}`, `a`/`a:hover` colors, and tiny basics (e.g. `button{font:inherit}`, `input{font:inherit}`), no other class rules.
- Lay out with flex/grid + `gap`. Grids: `display:grid; grid-template-columns: repeat(N, minmax(0, 1fr))`.
- `{{hole}}` is a dotted lookup into `renderVals()` only, never an expression. Mostly write copy as literal markup. Use `<sc-for list="{{items}}" as="item" hint-placeholder-count="5">` for repeated rows (data from renderVals) when it saves lots of markup; otherwise literal markup is fine.
- Always include the `<script type="text/x-dc" data-dc-script …>` block with `class Component extends DCLogic`. Classic JS, no imports, no innerHTML/appendChild, no global keydown handlers.
- Links between artboards: `<a href="Review-Back.dc.html" style="…button look…">Показать</a>` — style the `<a>` itself as the button; no `<button>` inside an `<a>`.
- Static controls that don't navigate: real `<button type="button">`, `<input>` with `<label>`. Icon-only buttons need `aria-label`. Decorative SVG `aria-hidden="true"`.
- Icons: inline stroke SVG (24 viewBox, stroke-width 1.75–2, `stroke="currentColor"`, `fill="none"`, round caps/joins). NEVER emoji anywhere. No fake phone status bar, no notch drawing.
- No gradients-as-decoration, no left-border accent cards, no lorem ipsum. Use the sample data below. The drawer row's 3×14 theme tick and the review card's 2×24 drag edge marks are short ticks inside a row or card, not borders, and are allowed (added 2026-10-25, picks D2 B and D4 Bold; see «Мобильный минимализм»).
- Touch targets ≥44px. Text contrast ≥4.5:1 (the tokens below pass).
- Safe areas: top padding 16px (no status bar drawn); bottom tab bar has 28px extra bottom padding (home indicator area).

## Slang level (the feature the user likes — make it visible but quiet)
Every word has a detected level on a 4-step scale: нейтр. → fam. → arg. → vulg. (verlan is a flag shown as *verl.* next to it).
- Draw it as a tiny 4-segment meter (each segment 10×3px, 2px gap, filled ink up to the level, rule color after) followed by the italic abbreviation: `▮▮▯▯ arg.` In vulg. the filled segments are red ink.
- Shown: on the card back, in Add-Filled (editable as a 4-option segmented control labelled «Уровень сленга» with an extra «verl.» toggle), in Import rows, in Folder rows (meter only), in Word-Detail. Library has a filter chip «Сленг: все ▾».
- In list rows (added 2026-10-25, `L-Kit` cell 06): the small meter with no label, and nothing at all for нейтр. (a neutral word is the default and says nothing; «нейтр. · verl.» still shows for a neutral verlan word where labels are on). On the review answer side the filled segments fill in once on reveal (D4 Bold, MOTION-SPEC §5.20). The control stays the segmented one in both forms (one control, not a meter-as-input).

## Copy rules
- Never «ИИ» / «AI» / «умный» / «магия» in UI, except the Settings section «ИИ» and its privacy line.
- Suggestions come in two quiet sections: «Словарь» (instant) and «Варианты» (richer, may load) — loading = 2 grey hairline skeleton rows, no "думает…".
- Theme picked automatically: chip selected + tiny muted caption «подобрано автоматически».
- Screenshot translation not present in image: italic text + mono tag `ДОГАДКА`.
- Re-sort button/screen: «Разложить по темам» / «Предлагаемые перемещения».
- Regenerate in word detail: «Обновить перевод и заметку» (removed 2026-10-23: split into the fields' own buttons, see «Раздать по полям»).
- Folds read «Ещё · <what is inside>» everywhere (added 2026-10-25), never «ещё ↓», «Ещё ›» or «Подробнее».
- Snackbars carry an undo: verb + object («Удалено · le blé», «Поле удалено») and «Отменить»; a second clause goes to the live-region text, not into the bar (added 2026-10-25, synthesis §2.10).
- Snackbars on phones (added 2026-10-25): a long message wraps to a second line (the bar grows from 48px; never «…»); every bar can be swiped away — sideways (it follows the finger and fades) or down — and leaves that way. From 768 up the bar stays one line.

## Cross-screen rules — phones (added 2026-10-25; from `docs/mobile-research/synthesis.md` §1–§2, approved with the «Мобильный минимализм» picks)
Desktop (from 768, the Desk* screens, sidebar and rail) is unchanged by every rule here: shared components get a phone-only branch.
1. **Each fact once, where you act on it.** The due count lives on what starts the review («Повторить тему 3», the red ▪ on a drawer, the Library subline); the total on «Все слова»; the day's numbers only in «План на сегодня». A second copy of a count is removed.
2. **At most one mono meta line per region at first paint.** Secondary facts become italic `.abbr` text, sit behind a tap, or go into the accessible name.
3. **Explanation lives at the entry point or in a first-run hint**, not on every visit (the swipe legend, «Почему позже?», captions). «не влияет на расписание» is said at the entry action (the theme menu's «Тренировка», the set start); during a practice round the dashed card rule says it; Done screens don't repeat it.
4. **No daily path gets longer.** Rare or destructive actions (pause, delete, disband, reset, data, sign-out, re-sort) go behind one «⋯», a sub-screen or an «Ещё» row; direction, theme, grading, adding a word and search keep their tap counts.
5. **One level of disclosure, opened in place.** ⌄ expands in place (Collapse), › navigates. A fold never opens a second stacked sheet.
6. **A number becomes an object** (deck edges, ticks, cells, the return timeline, the day strip, the mastery line) only if the exact value stays one tap away and in the accessible name.
7. **Visual = the brand's own objects**: the index card (and the blank card), hairline edges for quantity, ink lines for progress, the stamp. 1px rules only: no shadows, gradients, pills or illustrations.
8. **Motion only on real events, once** (MOTION-SPEC §5.17–§5.25). The stamp stays reserved for grading and «Готово на сегодня».
9. **Finished scaffolding leaves the screen** (import steps and bar, sort-plan steps, a finished summary, zero rows such as «Отложено 0»).
10. **Empty and neutral render nothing**: no neutral slang meter in rows, no zero counts, no empty section headings, no disabled «Добавить», no «Нет заметки».
11. **Dashed = "not yet on record"**: empty, unsorted («Входящие»), practice (the card's dashed top rule), proposed (a new theme, the next show in the history). Warnings keep their amber tokens; empty states use dashes in `--rule-dashed`.
12. **Red has two meanings.** Brand red `#c8331f` = "needs you / this is the word": the due ▪, the «Входящие» count, the ink underline, the card's top rule, the tab marker, the wait screen's «now» tick. `--again` = a past miss and always comes with a shape cue (an outline, a bar, a slash, the left side), never a fill alone, because the two reds look alike at 1–2px and misses must survive colour blindness. The exercise player's current tick is ink, not red. No red under-stroke for a held day: the plan sheet's empty slots say it.
13. **Sheets**: auto-height sheets show the grabber and no visible ✕; large and full sheets keep it (see «Sheets: grabber and ✕»).
14. **Headers**: sub-screens use the large title that collapses on scroll (MOTION-SPEC §5.22). Контекст is the exception: its field is the header.

- **How the day is planned** (what the user sees; `lib/core/plan.ts`; the connector's `study_summary` runs the same plan, so Claude and the app agree):
  - The study day starts at 04:00. Today's totals are fixed from each card's state at the start of the day, so «4 из 10», «К повторению» and «07 / 30» do not shift while studying, an undo puts them back, and every device shows the same day.
  - Order of the queue: learning cards that have come due always go first; then today's reviews with the new cards spread among them (one new card about every (reviews + 1)/(new + 1) reviews, as Anki does; «После повторения» puts them after the reviews); then learning cards due within 20 min. Learning cards due later wait: the wait screen below.
  - The two sides of one word are never within 5 cards of each other. When both sides are due today and neither is overdue, the RU→FR side moves to tomorrow. An overdue card is never moved. Neither rule applies when the review is set to one direction.
  - «Повторений в день» (default 200) caps the day's interday reviews; the learning steps of new words do not count. With more due than the cap («завал»), the reviews most likely to be remembered go first (then the easier ones), the rest are «Отложено» to the next day with their schedule unchanged, and no new words come in that day.
  - «Новых слов в день» (default 10, 0–30) is a ceiling counted in words, not cards. The day's number goes below it when the next 7 days already hold many reviews (full up to an average of half the cap a day, 100 at 200, falling to none at 80 % of it, 160), and it halves when fewer than 80 % of recent young reviews were remembered (only with 30 or more of them over the last 7 days). Paused themes take none of it. A theme filter narrows which words come, not how many.
  - Reverse side, «После 3 дней узнавания» (default): a word's RU→FR card starts once its FR→RU card has held for 3 days, never on a day FR→RU was reviewed, with its own daily allowance of up to the same number. So each day brings new words plus reverse sides of older ones, and days no longer alternate. «Назавтра» is the rule before the plan: RU→FR the day after, sharing one limit counted in cards. «Только узнавание» never shows RU→FR.
  - Order of new words, «По уровню языка» (default): lower levels first up to B2, then words with no level, then C1–C2. Slang, verlan and vulgar words come later (familier only a little). Ties go to the more frequent word, then the older one. «По темам»: theme by theme in the themes' order, the more frequent words first. «Как добавлены»: the oldest first, as before. Except with «Как добавлены», the themes take turns, at most max(2, ⌈day's number / 3⌉) new words come from one theme a day, and two words with the same Russian never come on the same day.
  - Where an older device has no plan yet, it starts from its «Новых карточек в день» (cards): new words = half of it, rounded up (15 → 8), within 1–30; the rest are the defaults.
